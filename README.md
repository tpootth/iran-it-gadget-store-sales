# Iran IT Gadget Store Sales Analytics

A data science coursework project exploring sales, customer segmentation, product assortment, promotions, return/cancellation risk, and geographic sales patterns for an IT gadget store in Iran.

## Analysis scope

- Sales exploration and geographic visualizations
- Customer segmentation
- Product assortment clustering
- Promotion analysis
- Return and cancellation risk

## Data source

[E-Commerce Sales Data Analysis and EDA on Kaggle](https://www.kaggle.com/datasets/erfan4524/e-commerce-sales-data-analysis-and-eda/data).
